# DOPAMINE MAXING

Swipe TikTok, YouTube Shorts, and Instagram in one feed.

- Live: https://dopamine-maxing.vercel.app
- Repo: https://github.com/willywonka773202-cloud/dopamine-maxing
- Handoff for the next model: [HANDOFF.md](./HANDOFF.md)

## Files

- `index.html` — splash, HUD, feed, add-url drawer
- `styles.css` — layout
- `app.js` — seed clips, embeds, 1/2/3 column modes, swipe lock

## Run locally

Any static server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
